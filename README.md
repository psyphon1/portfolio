# Chinmay Duse - Portfolio

A modern, minimalist portfolio showcasing AI/ML expertise, projects, and experience. Built with vanilla HTML/CSS for optimal performance and deployment.

## 🚀 Features

- **Responsive Design** - Works perfectly on all devices
- **Modern UI** - Glassmorphism design with smooth animations
- **Fast Performance** - No build tools, pure HTML/CSS
- **Dark Theme** - Easy on the eyes with carefully chosen colors
- **SEO Optimized** - Proper meta tags and semantic HTML

## 📁 Project Structure

```
portfolio/
├── index.html          # Main portfolio file
├── vercel.json         # Vercel deployment config
├── README.md           # This file
└── .gitignore          # Git ignore rules
```

## 🛠️ Local Development

Simply open `index.html` in your browser. No build process required!

```bash
# Option 1: Direct file
open index.html

# Option 2: Using a simple HTTP server (Python)
python -m http.server 8000

# Option 3: Using Node.js
npx http-server
```

## 🚀 Deployment

### Vercel

1. Push this repository to GitHub
2. Visit [vercel.com](https://vercel.com)
3. Import the repository
4. Click Deploy

The site will be live in seconds!

### Manual Deployment

Since this is pure HTML/CSS, you can deploy anywhere that serves static files:
- Netlify
- GitHub Pages
- Firebase Hosting
- AWS S3 + CloudFront
- Any web server
